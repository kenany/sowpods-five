# sowpods-five

5-letter words in [SOWPODS](https://en.wikipedia.org/wiki/SOWPODS).

## Example

``` javascript
import { sowpodsFive } from 'sowpods-five';
// => [
// =>   'aahed',
// =>   'aalii',
// =>   'aargh',
// =>   ...
// =>   'zygal',
// =>   'zygon',
// =>   'zymic'
// => ]
```

## Installation

``` bash
$ npm install sowpods-five
```

## API

``` javascript
import { sowpodsFive } from 'sowpods-five';
```

### `sowpodsFive`

An _Array_ of 5-letter words.
